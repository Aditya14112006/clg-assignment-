# Frontend Development — 15 Selected Practicals

This repository contains the 15 selected assignments from the 15-day roadmap.

## Run the projects
- For browser projects, open the folder's `index.html` in a browser.
- For Node.js exercises, open a terminal in the folder and run `node test.js` (or `node validate.js` for Assignment 9).
- No paid tools or external libraries are required.

## Selected practicals
1. Styled resume
2. Responsive menu
3. Dashboard layout
4. Grade calculator
5. Five reusable mathematical functions

8. Cart object
