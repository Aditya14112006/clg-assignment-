# Profile Card Project

A responsive profile card page built with HTML and CSS only (no frameworks, no JavaScript).

## Features

- Profile card built with the CSS box model (width, padding, border, margin)
- Responsive navigation menu with a hamburger toggle on small screens
- Flexbox layout for the hero section (intro and card side by side)
- CSS Grid layout for the skills section
- Media queries for tablet and mobile screens

## Files

- `profile-card-project.html` - the page, with the CSS included in a `<style>` tag

## How to run

Open `profile-card-project.html` in any browser. To test the responsive menu, make the browser window narrower than 640px.
