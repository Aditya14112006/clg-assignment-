## How to publish on GitHub
1. Sign in at https://github.com and create a new **public** repository named `frontend-development-practicals`.
2. Extract this project ZIP on your computer.
3. Open the extracted `frontend_15_assignments` folder.
4. Open a terminal in that folder and run:

```bash
git init
git add .
git commit -m "Add 15 frontend development practical assignments"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/frontend-development-practicals.git
git push -u origin main
```

5. Replace `YOUR-USERNAME` with your GitHub username.
6. Refresh the GitHub repository page and check that all folders and files are visible.
